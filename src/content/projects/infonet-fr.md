## The project

Infonet is a French B2B platform that provides certified financial and legal data about companies to investors and businesses.

## What I did

I joined the team working on the existing SaaS, so I didn't build it from scratch. I worked on several frontend features alongside the backend team, using Symfony with Twig templates, Bootstrap and SCSS, plus JavaScript and TypeScript on the client side.
